# Lab evidence

**Everything in this folder must come from our own lab run.** Nothing here
is generated by the tools, copied from the report's "expected" column or
taken from anyone else's lab. If a result differs from what we expected,
record what actually happened and explain it; that is a finding, not a
failure.

| Folder | What goes here |
|---|---|
| `E1/` … `E8/` | Transcripts from `experiments/eN_*.sh`, screenshots, and the filled-in `README.md` |
| `raw/` | Created by `experiments/collect_results.sh` (all VM transcripts plus `SHA256SUMS`) |
| `lab_config/` | OPNsense config export with secrets removed, and `pfctl -sr` output |
| `environment.md` | Versions and host specification (fill in below) |

Naming: `E<n>_<what>_<YYYYMMDD-HHMM>.png` for screenshots, so they sort by time.

After the run, copy each Observed result into report Table 11.2
(`\observed` cells) and the `observed_in_lab` column of
`part3_rulebase_policy/verification/verification_matrix.csv`.
